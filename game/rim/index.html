วิธีเล่น

รับโน้ตที่ไหลลงมาตรงขอบแผ่นเสียงให้ลงจังหวะ

คีย์บอร์ด + เมาส์

  • ส่ายเมาส์ (หรือ ← →) ย้ายตัวรับไปเลนของโน้ต
  • Space คลิกโน้ต · ค้างไว้ตามโน้ตยาว
  • F เปิด/ปิด FX · ล้อเมาส์ หมุน dry/wet
  • Enter เริ่ม/หยุด · Esc ปล่อยเมาส์

DJ controller

  • ครั้งแรก: ตั้งค่า → ต่อเครื่อง
  • หมุนจาน ย้ายเลน · crossfader คลิก/ค้าง
  • ปุ่ม FX + ปุ่ม dry/wet · PLAY เริ่ม/หยุด

โน้ต

  • ชิ้น = คลิกครั้งเดียว
  • ท่อ = เปิดค้างจนสุดท่อ
  • ซิกแซก = ค้างไว้ + หมุนตามเส้น
  • FX Zone = เปิด FX → หมุน dry/wet → ปิด FX
  • เต็มเพลง: คอมโบจนเกจเต็ม = Fever freestyle

ตั้งค่า

เสียงดังตอนกดจริง ไม่ใช่ตอนที่โน้ตควรโดน · ใช้หูฟังบลูทูธ (หน่วง) แนะนำให้ปิด

น้อย = ตัวรับไวขึ้น · มาก = ช้าลง

ดูท้ายเพลง: "กดเร็วไปเฉลี่ย X ms" → ลดค่านี้ลง X (ติดลบได้) · "กดช้าไป" → เพิ่มขึ้น
