วิธีเล่น

รับโน้ตที่ไหลลงมาตรงขอบแผ่นเสียงให้ลงจังหวะ

คีย์บอร์ด + เมาส์

  • ส่ายเมาส์ (หรือ ← →) ย้ายตัวรับไปเลนของโน้ต
  • Space คลิกโน้ต · ค้างไว้ตามโน้ตยาว
  • F เปิด/ปิด FX · ล้อเมาส์ หมุน dry/wet
  • Enter เริ่ม/หยุด · Esc ปล่อยเมาส์

DJ controller

  • ครั้งแรก: ตั้งค่า → ต่อเครื่อง
  • หมุนจาน ย้ายเลน · crossfader คลิก/ค้าง
  • ปุ่ม FX + ปุ่ม dry/wet · PLAY เริ่ม/หยุด

โน้ต

  • ชิ้น = คลิกครั้งเดียว
  • ท่อ = เปิดค้างจนสุดท่อ
  • ซิกแซก = ค้างไว้ + หมุนตามเส้น
  • FX Zone = เปิด FX → หมุน dry/wet → ปิด FX
  • เต็มเพลง: คอมโบจนเกจเต็ม = Fever freestyle

ตั้งค่า

สีและบรรยากาศของสนาม · ไม่มีผลกับการตัดสิน

เสียงดังตอนกดจริง ไม่ใช่ตอนที่โน้ตควรโดน · ใช้หูฟังบลูทูธ (หน่วง) แนะนำให้ปิด

หมุนจานแล้วตัวรับไปผิดทาง = ติ๊กช่องนี้

ติ๊ก = ตัวรับตามจานทันที เหมาะคนคล่องจาน · ไม่ติ๊ก = ดูดเข้าเลน กันจานสั่น เหมาะมือใหม่

ต้องเลื่อน crossfader ออกจากฝั่งปิดกี่ mm ถึงนับว่าเปิด (ระยะเฟดเดอร์มาตรฐาน 45.7 mm) · น้อย = คัทไว · มาก = ต้องเลื่อนไกลขึ้น · 0 = ค่าเริ่มต้น

จานคอนโทรลเลอร์ · น้อย = หมุนนิดเดียวก็ข้ามเลน · มาก = ต้องหมุนไกลขึ้น

น้อย = หมุนนิดเดียวก็ข้ามเลน · มาก = ต้องหมุนไกลขึ้น

ภาพตัวรับขยับนำจานจริง ชดเชยความหน่วงที่ตาเห็น · มากไป = ตัวรับเลยแล้วดีดกลับ · ไม่มีผลกับการตัดสิน

น้อย = ตัวรับไวขึ้น · มาก = ช้าลง

ดูท้ายเพลง: "กดเร็วไปเฉลี่ย X ms" → ลดค่านี้ลง X (ติดลบได้) · "กดช้าไป" → เพิ่มขึ้น

เวลาที่โน้ตวิ่งจากปลายถนนถึงตัวรับ · มาก = โน้ตช้า อ่านทัน · น้อย = โน้ตเร็ว
